# Controle da Obra – Casa Ramon e Talita

Aplicativo de acompanhamento da obra, com orçamento detalhado, cronograma, PLS, custos, Curva ABC e programação de compras.

## Estado atual

- Aplicação web local-first.
- Dados iniciais incorporados ao aplicativo.
- Próxima etapa: autenticação e sincronização compartilhada via Firebase/Firestore.

## Uso

A versão publicada será disponibilizada via GitHub Pages.
